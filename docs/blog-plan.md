# Blog Content Plan — Solent Marine Outboards UK (v2 — corrected)

## What changed from v1
v1 produced only 10 posts by merging distinct clusters together (e.g. every accessory type — stands, covers, locks, trolleys, brackets, fuel tanks — got squashed into one "Accessories Guide" post). That breaks the skill's **one-cluster-one-URL rule**: each of those is its own distinct search cluster and deserves its own page, or they cannibalise each other. This version has **20 posts to build first + 6 more backlogged for later**, reclustered properly (max 15 keywords/cluster) and expanded with the FAQ-mining pass (which surfaced strong how-to guide material — winterizing, flushing, starting procedure, serial-number identification — that v1 missed entirely because it only looked at the Vol 50+ pool, not the full dataset).

No blog route exists yet — see `product-gaps.md` Gap 2 for the build note (`src/app/blog/`, mirroring the existing `/product/[slug]/` pattern).
